# Project instructions

## README maintenance

- Keep `README.md` bilingual, with separate Turkish and English sections.
- When a change affects setup, dependencies, features, usage, limitations, or project status, update the relevant content in both languages in the same change.
- Keep both language sections accurate and aligned; do not describe planned or unverified behavior as implemented.
- Keep the short GitHub description near the top accurate when the project's purpose changes.
- Before finishing, review both README sections for consistency with the repository and the changes made.
